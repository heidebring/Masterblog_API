# Masterblog Project

This project provides you an API to manage local saved blog posts. You can view, add, update and delete posts. You can also sort the posts by title or content. Also you can filter the posts by title or content.

## Installation

To install this project, simply clone the repository and install the dependencies in requirements.txt using `pip`

## Usage

To use this project, run the following command - `python backend/backend_app.py`. This will start the flask application.
